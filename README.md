# Bikcraft

Projeto front-end desenvolvido como **trabalho de conclusão de curso** da Origamid.

A Bikcraft é uma **loja fictícia de bicicletas**, criada para consolidar os fundamentos de HTML, CSS e JavaScript, com foco em estrutura, layout responsivo e animações básicas.

---

## Sobre o Projeto

Este projeto tem caráter **educacional** e foi desenvolvido ao final do curso para aplicar, na prática, os principais conceitos aprendidos durante a formação.

---

## Objetivos

- Praticar HTML semântico
- Desenvolver layouts responsivos com CSS
- Aplicar JavaScript básico para animações e interações
- Organizar um projeto front-end do zero até a entrega final

---

## Stack Utilizada

- **HTML5**
- **CSS3**
- **JavaScript (Vanilla)**  
  Utilizado principalmente para animações e interações simples.
